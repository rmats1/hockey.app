# Hockey App — documentación

Este directorio es un vault Markdown compatible con Obsidian para documentar la aplicación Android.

## Índice

- [[Arquitectura]] — estructura actual y límites entre capas.
- [[Build y dependencias]] — sistema de compilación y librerías principales.
- [[Navegación]] — rutas y flujo de pantallas.
- [[Pantallas]] — inventario funcional de la aplicación.
- [[Estado técnico]] — problemas conocidos y próximos puntos de atención.

## Cómo abrirlo en Obsidian

En Obsidian, selecciona **Open folder as vault** y elige esta carpeta `docs/`.

La documentación usa enlaces internos de Obsidian (`[[...]]`) y puede editarse junto con el código en Git.
